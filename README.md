# homepage

Portfolio Iqdam Shidqi. Situs statis (HTML, CSS, JS), tanpa build step.

```
index.html          halaman utama
css/tokens.css      token desain (warna, font, spacing) + komponen dasar
css/style.css       gaya khusus halaman
js/animations.js    animasi (split text, fade, counter, reel, parallax, marquee, menu mobile, tab)
js/site.js          label section aktif di sidebar
assets/cv/          CV untuk tombol Download CV
assets/photos/      foto dinding & profil (lihat README di dalamnya)
```

Jalankan lokal: `python3 -m http.server` di folder ini, lalu buka http://localhost:8000.
