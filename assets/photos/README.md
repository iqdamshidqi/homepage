# Foto

Taruh foto di folder ini dengan nama berikut. Selama file belum ada, halaman menampilkan teks dari CV di tempatnya.

| File | Dipakai di |
|---|---|
| `profile.jpg` | Foto profil bulat di sidebar |
| `photo-01.jpg` … `photo-04.jpg` | Baris 1 dinding foto (bergerak ke kiri) |
| `photo-05.jpg` … `photo-08.jpg` | Baris 2 dinding foto (bergerak ke kanan) |
| `photo-09.jpg` … `photo-12.jpg` | Baris 3 dinding foto (bergerak ke kiri) |

Rasio tile dinding foto 7:3 (misalnya 1400×600 px). Foto tampil grayscale dan jadi berwarna saat di-hover.
